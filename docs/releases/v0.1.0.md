# v0.1.0

## Catalog and pins

- Initial 17-application Windows 11 x64 catalog.
- RealVNC Server is pinned to package 7.18.0.14 and blocks v8+.
- RealVNC Classic Viewer targets 7.18.1; NoMachine is pinned to 9.8.2 and blocks v10+.

## Manual actions

- Configure the Clash subscription and verify connectivity before rerunning network-blocked items.
- Complete Microsoft Store, ChatGPT, JetBrains, RealVNC, and Ubuntu account or first-run steps yourself.
- Confirm eligibility for the Xftp/Xshell Home/School license before downloading those installers.

## Known limitations

- Clash's direct GitHub fallback remains disabled until an immutable signed installer and exact SHA-256 are reviewed; WinGet is the active installation path.
- Xftp 8 Home/School, Xshell 8 Home/School, and RealVNC Classic Viewer 7.18.1 return `ManualActionRequired` until complete seed metadata is reviewed.
- A release tag is blocked until the matching Windows 11 VM acceptance checklist is complete and repository-level immutable releases are enabled.
